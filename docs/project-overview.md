# Laravel Enterprise Ecommerce

This is a hybrid Laravel ecommerce project with Web MVC and REST API modules.

## Tech Stack

- Laravel 12
- MySQL
- Laravel Breeze
- Laravel Sanctum
- Spatie Permission
- Repository Pattern
- Service Pattern
- Form Requests
- API Resources
- GitHub

## Main Modules

- Authentication
- Product Management
- Cart
- Wishlist
- Orders
- Payments
- Wallet
- Inventory
- Admin Panel
